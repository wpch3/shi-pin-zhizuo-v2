| 项目 | 设定 |

### 外貌反差锁定（防止被画成同一个人）

- **小眠（基准，不可动）**：浅亚麻奶茶色松散双低马尾 + 头顶微翘呆毛 + 半透明碎刘海；幼态短圆脸、粗黑微垂半睁上眼睑、低饱和灰蓝无高光瞳孔、淡红棕眼下卧蚕、极简点鼻细线嘴；鼠尾草绿薄针织开衫 + 米白小翻领连衣裙 + 奶油白小花发夹。
- **知夏（新角色）**：深栗／黑茶色齐肩内扣短发（或利落高单马尾）、无刘海偏分；鹅蛋脸偏长、上挑细长眼、暖琥珀色瞳孔、笑起来有浅浅梨涡；身形比小眠略高、站姿舒展；雾蓝衬衫 + 浅灰针织背心 + 深色细腰带，可加一副细金属框眼镜。
- **明确禁用**（避免撞脸）：绿色系主色、双低马尾、呆毛、圆脸半睁眼、灰蓝瞳、奶油白发饰、米白连衣裙。

### 画风锁定（100% 对齐 `new_character.png`）

- 唯一风格锚：`new_character.png`；生成时必须作为参考图输入，并明确「不同人物、不是同一个人」。
- 必须保留：素描感 2D 手绘铅笔线稿（可见轻重变化的墨线）、平涂哑光赛璐璐上色、低饱和柔和色、无高光瞳孔、极简点鼻与细线小嘴、手绘短排线阴影、暖调虚化室内背景。
- 明确排除：水彩晕染、马克笔wash、厚涂／笔触感、写实光影、强对比美漫描边、3D 渲染感（这些在上一轮被否过）。

### 交付与沿用流程

1. **步骤一（先做）**：新角色立绘两候选 → 用户挑选其一 → 定稿 `new_character_lv2.png` → 按小眠卡版式出 `character-card-zhixia.png` 设定卡。画风确认通过后才进入整话，避免整话返工。
