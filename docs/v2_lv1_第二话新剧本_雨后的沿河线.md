# V2 · LV1《陪妹妹出门约会》第二话：雨后的沿河线

> **状态：剧本提案，待用户认可；尚未按本稿生成原画。**本稿是第二话的新方案，独立于仓库中已制作的旧第二话《不否认的那句》，不覆盖旧剧本和成品。LV2 暂时搁置，不引入阿澄。

## 承接与发展

第一话结束时，小眠希望以后的约会都和哥哥一起，哥哥答应陪她。第二话在约定的下一次出门展开：**小眠第一次认真安排约会，却遇上计划取消；两个人一起把不完美的一天变成自己的约会。**她从等待哥哥安排，变成主动提出路线；哥哥不止口头承诺，而是在计划失效后留在她身边。

与第一话的区别：不再走换装、买发夹、甜品、夕阳牵手的流程；花发夹只是延续性细节，不重复戴发夹。旧第二话以店员误认为推动，本稿不沿用那个情节。不是时间表式打卡，而是一件意外贯穿全话。

## 人物、画风与版式

- 小眠：沿用 `new_character.png` 与第一话成品；浅亚麻奶茶色松散双低马尾、呆毛、碎刘海、灰蓝色无高光瞳；鼠尾草绿开衫、米白小翻领连衣裙、哥哥上次送的奶油白小花发夹和浅米色斜挎包。
- 男主：第一人称 POV，不露正脸；需要入画的手或身体须从镜头位置自然进入。两人一贯自然亲昵、双向偏爱，正文不解释身世关系。
- 画风：素描感铅笔线、低饱和哑光平涂，参照 `new_character.png`，不转水彩或厚涂；无白色瞳孔高光。
- 暂定四页正文，每页一个连续画面；具体气泡大小与位置以后续画面留白为准。男主回应分独立框，一句只答一个点。

## 第 1 页：今天的安排

**画面瞬间：**傍晚出发，公园入口附近。小眠侧身倒退一步，回头望向镜头，把自己折好的小纸条举起来；一只手捏着纸条，另一只手按住快被风吹乱的裙摆，双低马尾随转身轻轻扬起。纸条上可辨认“露天电影”。她有点得意，笑得克制又藏不住期待。哥哥的手自然从前景伸出接纸条，不挡住她的脸。

**小眠气泡 1：**“上次哥哥说，以后也会陪我约会。”

**小眠气泡 2：**“所以今天，让我来安排！”

**哥哥回应框 1：**“我记得。”

**哥哥回应框 2：**“那今天听小眠的。”

**情绪与作用：**接住第一话承诺。她主动安排，不是复刻第一次出门前的装扮与夸奖。

## 第 2 页：计划被雨打断

**画面瞬间：**露天电影入口旁的雨棚下，大雨刚落。公告板清楚写着“今日露天放映因雨取消”。小眠抱着折起的行程纸，肩膀微缩，视线从公告移向镜头；她努力笑一下，却有一点失落。哥哥从镜头侧伸出手，为她接住被风掀起的纸角。两人都在雨棚下，不把人画进雨中挨淋。

**小眠气泡 1：**“我查了好久，才挑到这场电影……”

**小眠气泡 2：**“结果今天的安排，一开始就失败了。”

**哥哥回应框 1：**“想看的电影，我们以后再来。”

**哥哥回应框 2：**“今天和你出门，没有失败。”

**情绪与作用：**取消是明确的外部意外；她会失落，但不靠误会或旁人刺激推进关系。

## 第 3 页：换一条路线

**画面瞬间：**公园旁有顶棚的公交站。小眠从站牌旁回头，手指着路线图上的“沿河线”，眼睛亮起来；另一只手把刚才的纸条折成小小的车票模样。公交车正停稳在站边，车门还在画面后方，空间关系清楚；哥哥的手在前景撑着小伞，伞边在两人头顶，不出现无来源的手。她从失落转为有点调皮的兴奋。

**小眠气泡 1：**“这辆车会沿着河边走！”

**小眠气泡 2：**“哥哥，陪我坐到终点站好不好？”

**哥哥回应框 1：**“好，下一站听你的。”

**哥哥回应框 2：**“今天的车票我来收好。”

**情绪与作用：**小眠自己发现并提出新计划，哥哥响应；纸条从“失败的行程”变成两人的小车票。车票只是纸折的纪念物，乘车仍按正常方式付费，不暗示拿纸条乘车。

## 第 4 页：雨后的新约定

**画面瞬间：**公交车行驶在沿河路上，小眠坐在靠窗位置，身体微微朝镜头侧过来，把折好的小纸票夹进哥哥手中的透明票夹；哥哥手从前景扶住票夹。窗外雨渐停，河面透出一点晚霞。她先前紧绷的肩膀松下来，眼里有笑，脸颊微红；不是第一话夕阳街上牵手画面的复刻。窗外景色与车窗内的人物处于同一画面，不加分格。

**小眠气泡 1：**“电影没看到，可是这段路好漂亮。”

**小眠气泡 2：**“下次还是我来安排，你也会跟我走吗？”

**哥哥回应框 1：**“会。”

**哥哥回应框 2：**“去哪里都想和你一起。”

**情绪与作用：**第一话是承诺陪伴；这一话两人共同应对意外，小眠确认自己也能带着哥哥走。折纸票留作具体纪念，既收束这一话，也给下次约会留空间。

## 自检与待确认

- 四页各是单一瞬间：出发 → 取消 → 小眠提出新路线 → 车上收束；没有一页多个格子。
- 出发时想看的露天电影因雨取消，之后坐沿河公交，结尾的晚霞是雨渐停后的窗外景色；纸条从行程表变成纪念票，动作连续。
- 小眠有得意、失落、重新兴奋、放松四种递进反应；姿态分别为转身举纸、抱纸侧望、指路线、侧身夹票，避免四页同一正面笑脸。
- 第一人称镜头持续成立；前景手仅在接纸、扶纸、撑伞、扶票夹时出现，后续生图须逐页检查手的来源与数量。
