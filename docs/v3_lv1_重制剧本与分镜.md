3. **全程严守第一人称（POV）一镜到底**：
   - P2 初见改为男主第一人称手握冰美式与透明A4分镜夹望向窗边的她（去掉原版占 1/3 画面的男主后脑勺）；
   - P9「四十年后」改为**第一人称俯视自己苍老起皱的双手**在数位屏上画纯爱分镜，孙女小手从画面右侧探入指着屏幕说话，彻底修掉原版“第三人称陌生老头盘腿塞矮桌 + 工具倒退回毛笔墨水”的割裂感。
4. **补齐“礼貌而干净利落的拒绝”核心戏剧闭环（P7）**：原版直到结尾男主都没开口，文不对题；新版在 P7 补上男主鼓起勇气递出手机想加联系方式，被她弯眼礼貌婉拒（「抱歉呀，老师。接我的人已经到窗外啦」），窗外男友为正常暖色柔和侧影（修掉原版柯南黑影犯人脸）。

6. **排版纪律全面校正**：全书统一由脚本在 `1440×1920` 画布绘制 `margin=36px` 的干净手绘感画框；所有气泡与旁白框严守 `≥ 56px` 安全内边距，对白字号统一 `34–40px`（彻底杜绝原版 `26px` 蚂蚁字、压黑框边线、尾巴扎耳朵/发辫的问题）。
