# 创作铁律与制作流程

> 本文件记录用户明确提出的长期要求。具体项目的既有角色、画风和版式约束仍须查阅对应设定；不得用本文件取代已有设定或擅自改写用户的主题。

## 一、核心铁律：观察、思考、自我纠错

1. **先观察**：动手前查看仓库及当前分支已有的设定、剧本、参考图和成品；需要时检查远端当前分支，不凭记忆宣称资料不存在。
2. **再思考**：弄清项目编号、当前制作阶段、承接关系与用户真正的目标，考虑因果、空间、连续性及画面可执行性，不靠堆设定掩盖问题。
3. **主动纠错**：逐项检查自己的剧本、生成图和成品；发现偏差主动修正，再交付。不可把本应由制作者完成的基本检查和判断推给用户；不确定之处要如实说明，不假装通过。
4. **尊重既定主题与决定**：不把个人偏好当成用户要求，不擅自改变核心主题。用户明确废弃的故事不自行恢复；项目搁置不等于删除其原文件。
5. **上传成果**：用户要求上传时，将本次相关铁律及成果提交、推送至当前工作分支；保留既有成品，不覆盖无关项目。后续成果按用户要求及时上传，说明完成或未完成状态。

## 二、剧本与画面条例

1. **后续要延续，也要发展**：从前一话的真实事件、道具或承诺出发，引入新的情境和人物选择；不得换词、换镜头重复上一话剧情。
2. **动作和表情要生动**：人物有主动反应、姿态变化和自然动作衔接；每页选择一个可画出的瞬间，避免一味正面微笑、固定站姿或机械排列。表情变化应与情节相符。
3. **连贯与真实**：交代人、物、手的来源及空间关系，保持人物外貌、服装、道具跨页一致；避免凭空多手、动作冲突、镜头视点混乱。
4. **一页一个画格**：当前 V2 LV1 制作先采用一页一个连续画面，不拼多格、不用无关插图凑页；实际页数根据故事需要确定，不把页数当成固定上限。
5. **剧本确认在前**：先交剧本，用户认可后再生成整话原画；生成前仍须核对已确认剧本与风格参考。
6. **生图与验收**：采用单图生成，由制作者逐张对照参考和剧本检查，不使用让用户从多个生图候选中选择的模式；不合格则自行修正，诚实标注尚未解决的问题。
7. **V2 LV1 的甜度与亲近感**：关系推进不仅靠一起出门或口头约定；以双向主动、自然亲密的互动和明确的情感回应体现甜蜜，同时避免机械重复上一话动作。
8. **错图重生，不反复沿错图修**：如果构图、第一人称视角、动作或肢体关系根本不对，直接从确认的角色／风格锚点重新生成，错误图不作为参考；只有构图与主体关系已正确、剩余问题局部且适合修补时才编辑原图。每次仍须自检，不把反复试错交给用户。
9. **不固化镜头**：第一人称不等于每页女主正面看镜头；根据剧情主动选择背影、侧面、俯视等合理镜头。例如坐着从背后抱住女主，只要动作、空间和视点清楚，就不强行画成正面。
10. **画风不可偏移**：始终以该项目已确认的原始风格锚和成品为准，不拿未通过的图当画风参考。生图后对照线条、平涂、色调、面部和瞳孔检查；风格明显偏移则重生，不以“同样是动漫风”冒充一致。V2 LV1 锚点为 `new_character.png`。
