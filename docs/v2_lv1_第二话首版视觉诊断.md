# V2 LV1 第二话首版视觉诊断与修正

## 结论

首版的主要问题不仅是局部细节，而是画面没有把剧本演出来：多页都变成女主正面半身望镜头、手在画面前方，动作和景别趋同。单看画面，约会准备、计划落空、发现新路线、并排靠近、交付纪念物的递进不够清楚，过于依赖画外台词。原试排不作为定稿。

## 按页观察与修正方向

1. **出发：**人物回头牵手有动势，行程纸能提供线索；但袖口处有额外手部疑点。修正手的归属，并突出藏纸、邀请与前进动作，避免落成正面站姿。
2. **避雨厅：**首版是站着被碰肩，不是拥抱。按用户修正为**坐在避雨厅同一张长椅上，哥哥以第一人称抱着小眠**，她靠在哥哥身边，画面体现失落后安心。窗外有雨，背景可清楚交代放映取消。`art/v2-lv1-chapter-02-revised-v2/page-02.png` 是重画试验，坐姿、靠近有改善，但手臂环抱及镜头归属仍不够明确，**未通过**，不能替换首版成品或宣称已完成。
3. **新路线：**首版有指站牌，但与前页一样基本正面注视镜头；发夹换边。应加强小眠转身发现站牌、主动拉哥哥去乘车的方向感，统一发夹；不要增加来源不明的手。
4. **车上靠近：**首版是正面伸手而不是可信的并排坐。应从邻座第一人称斜侧视角，让车窗、座椅和手臂说明两人并排，小眠主动抱住哥哥手臂；与 P2 的被安慰拥抱区分。
5. **交付纸票：**首版同样是正面半身，靠肩未表现。应利用第一人称稍俯看的近景，以放进哥哥掌心的纸票和小眠自然靠近的侧脸表现信任与告白，既与 P4 区分，又让两人的手都能辨认。

## 跨页验收

- 全片统一服装、花夹、角色比例、无白色瞳孔高光；手臂必须从镜头边缘自然进入，不能凭空出现。
- 时间与天气连续：傍晚 → 降雨 → 雨中候车 → 雨渐停的沿河车程；不应候车变成深夜、下页又回白天。
- 每页一个连续画格。景别和姿态随情绪变化，不用强迫每页都正面露脸，也不靠遮住脸或模糊消除空间矛盾。
- 不为赶进度把试验图拼成定稿；逐页看原画与台词是否相互支持，再正式排版。
